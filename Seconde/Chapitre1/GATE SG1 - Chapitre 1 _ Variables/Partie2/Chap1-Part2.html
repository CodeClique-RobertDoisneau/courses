Partie 2 : Les types

Comme tous les objets, les variables ont un type. Par exemple, si on prend les fruits, les variables sont comme des fruits : il existe plusieurs espèces.

De même, si elles sont différentes, on ne peut pas forcément les mélanger ou faire les mêmes choses avec.

Sans plus tarder, les types les plus simples, appelés les types primitifs, sont :

  • Int - entier : c'est le type des entiers. Ex : 5, 67, 9554447
  • Float - flottants : c'est le type des nombres décimaux. Ex : 56.0, 67.373894
    ATTENTION : les virgules sont des points !
  • Str (string) - chaîne de caractères : tout texte doit être entre guillemets.
    Ex : "bonjour" (attention, bonjour sans guillemets n'est pas une chaîne).
    Ex : 'Salut tout le monde' ou " Salut :), j'adore python et toi ?"
  • Bool - booléens : True ou False (1 ↔ True, 0 ↔ False). Très utile malgré son apparence simple.

POUR ALLER PLUS LOIN

  • List - liste : collection d'éléments de n'importe quel type, entre crochets.
    Ex : [3,5], ["Adidas ou Nike ?"], [True, 45, ["perso Adidas"]]
  • Dict - dictionnaires : association clé → valeur, entre accolades.
    Ex : {"écurie 1" : [], "écurie 2" : []}

Il existe davantage de types comme les tuples ou les tableaux, abordés plus tard.

Quel rapport avec les variables ?

Les variables peuvent changer de type au cours du programme.

Exemple : x = 4 puis x = "changement de type".

EXERCICE

1. Initialise record_de_but = 34. Quel est le type officiel ? → Int

2. Change record_de_but = "non défini". Quel est le type maintenant ? → Str
