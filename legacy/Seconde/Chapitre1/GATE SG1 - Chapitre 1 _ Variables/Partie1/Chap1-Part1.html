Partie 1 : les variables

En Python, une variable est un identifiant (une étiquette). Elle représente un espace réservé en mémoire où l’on peut stocker une valeur.

Manipulation des variables

L’opération d’affectation consiste à placer une valeur à droite du signe = et le nom de la variable à gauche.

Exemple : créer la variable x avec la valeur 2 :

>>> x = 2

On peut ensuite la modifier :

>>> x = 3

Après chaque affectation, la variable renvoie la dernière valeur assignée :

>>> x = 2
>>> y = x

Dans cet exemple, y vaut 2.

EXERCICES – Manipulation des variables

  1. >>> x = 3
    >>> y = x
    Quelle est la valeur de y ?
  2. >>> x = 56
    >>> y = 46
    >>> x = y
    Quelles sont les valeurs finales de x et y ?
  3. Associez à la variable z la valeur 4.

Noms de variables

Les noms peuvent contenir des lettres, des chiffres et le caractère souligné _. Ils ne doivent pas commencer par un chiffre ou par _, et il faut éviter les mots réservés de Python.

Exemple d’un bon nom : nombre_bonbons.

Python est sensible à la casse : variable et Variable sont différents.

EXERCICES – Noms de variables

  1. >>> variable = 3 → Que renvoie variable ?
  2. >>> variable = 45
    >>> Variable = 56 → Que renvoie variable et Variable ?
  3. >>> test = 1
    >>> TEST = 0
    >>> TEST = test → Que renvoie TEST et test ?

Résumé

Une variable associe un nom à une valeur via l’opération =. Elle peut être modifiée et renvoie toujours la dernière valeur assignée.

Vous maîtrisez maintenant la création et l’utilisation des variables en Python ; la suite portera sur les différents types de données.
